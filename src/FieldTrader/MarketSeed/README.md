# 暗区情报站初始参考数据

数据来源：[暗区情报站物品列表](https://aqtwwx.net/item-list)，网站面向《暗区突围：无限》。
读取日期：2026-10-21。网站与 FieldTrader 均非官方实时成交凭证。

通过普通浏览器读取公开渲染的 71 页（每页 20 项，末页 16 项），共 1,416 行；没有访问登录后内容，没有模拟签名调用接口。直接接口请求返回 403 后改为普通网页浏览；网站社区共建页面称对外 API 尚在开发测试中。本包离线使用，不会在启动时联网抓取网站。

- `aqtwwx.json`：1,243 个唯一有效名称，1,150 个无冲突正整数参考价。
- `source-audit.json`：空名称、重复名称、价格冲突及分类计数。
- 57 行名称为空被排除；116 行重复名称被合并。93 个名称保留目录但价格留空（同名价格冲突）。这不是全游戏物品覆盖承诺。
- Key 是规范化名称的本地 SHA256，不是游戏或网站物品 ID。没有通过名称推断配方、需求数量、可交易库存或转售资格。
- 页面仅显示相对更新时间，没有可核实的精确行情时刻。因此 SourceUpdatedAt 为 null，FetchedAt 是页面读取时间；无法据此学习游戏的分时价格规律。
- Category 保留网站分类路径，导入 ItemCatalog 时主分类取第一段；分类是否等同当前游戏市场分类尚未实机核对。
- 钥匙和子弹仅标注特殊类别；ResaleEligibility 始终 Unknown。Material/Product 初始未标记，RecipeStatus 为 Unverified。

首次打开市场巡查窗口时，在后台事务中导入。已存在同名商品映射至原 ID，不覆盖人工字段、候选确认状态、巡查时间、OCR 数据或成交凭证。来源第一次导入后，后续启动不自动更新；同版本内容变化报错。新版本快照也不会偷偷追加为历史价格，未来需单独实现明确的更新流程。

数据库版本 3 新增 SeedImports、SeedItemSources。价格写入 PriceObservations 的 Reference / website-reference 分区，置信度字段为 0（不冒充模型置信度）、数量未知。源时间缺失时 ObservedAt 存读取时间，并在来源表明确区分。调度统计只读取实时 OcrObservation / market-card，不读取 Reference。初始覆盖率为 0 / 1243，任何交易仍须当前游戏价格及后续 C/D 决策、验证流程。

准备工具：`tools/MarketReplay/prepare_market_seed.py` 只转换已保存的网页 DOM 数据，不请求网络。数据事实保留来源署名，不包含网站图片或文章内容。网站数据可能随版本、价格、分页顺序变化；应以当前游戏界面为准。
