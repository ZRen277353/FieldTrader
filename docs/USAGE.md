# 使用说明

[返回首页](../README.md)

## 1. 安装与升级

从 [Releases](https://github.com/yu6339096-creator/FieldTrader/releases/latest) 下载安装版 EXE，退出旧版后覆盖安装即可。软件已包含运行组件和完整初始数据库。

便携版解压后运行 `FieldTrader.exe`，不要只移动单独 EXE；运行库、数据、图片和第三方组件需保留在一起。

普通听声识物无需 VB-CABLE。需要把真人麦克风和音效送入游戏时，首次安装标准 VB-CABLE：在安装完成页勾选组件，或在语音板点击“安装虚拟麦克风”，接受 Windows 管理员确认，在官方窗口点击 Install Driver 并按提示重启。驱动不会在应用启动时静默安装。

## 2. 听声识物

选择游戏实际输出声音的设备，点击“开始监听”或按默认全局快捷键 `Alt + W`。先确认主窗口波形/频谱有响应，再观察识别结果。软件没有收到游戏音频时，调低匹配阈值无法解决采集问题。再按一次快捷键会停止监听并同步隐藏悬浮窗；快捷键可在“软件设置”中点击输入框后重新录入。

支持多个物品共享声音组；图片摆放的横竖方向和占格信息用于筛选候选，不要求声音按方向分别录制。

悬浮窗置顶显示当前与上一轮有效结果；不确定或未匹配时保留最近有效候选并提示。每个物品名称下方显示参考价，单位为万，例如 `155W`、`7.5W`。物品图片的透明区域使用网站标注的品质颜色，文字区保持中性背景。价格、品质、占格、横竖方向和拾取音效来自随软件打包的暗区情报站“行商听声鉴宝”图鉴快照，不是实时成交价。

规格切换、透明度和排序方式默认展开。排序可按价格、品质或名字选择升序、降序。透明度和排序方式会自动记忆；规格筛选不会记忆，重新打开软件时恢复为“全部规格”。主窗口最小化、隐藏 HUD 不会停止监听；点击停止、再按全局快捷键或退出整个软件才会停止。

品质背景颜色可在主窗口“软件设置”中修改，默认值：红色 `#361c1a`、金色 `#2a1d0e`、紫色 `#1d1a27`。保存后会立即重新合成当前物品图片。

悬浮窗可直接拖动上下左右边缘或四角调整大小，右下角带有缩放标记。尺寸会自动记忆；锁定后不能移动或缩放。

## 3. 游戏语音与真人麦克风

1. “真人麦克风”选择自己的实体麦克风或耳麦，不要选择 CABLE Output。
2. “混音送到”选择 CABLE Input。
3. 点击“开启麦克风混音”。
4. 游戏麦克风选择 CABLE Output，游戏耳机输出保持原来的设备。
5. 点音效播放按钮，或在游戏前台使用卡片显示的全局快捷键。

“本地试听设备”仅用于混音关闭时试听。开启混音后，音效与真人声一起进入选定的虚拟线路。界面显示“仅本地试听”时，不能据此判断队友收到声音。

### 按键说话 / 自由说话

按键说话默认 T，可改成游戏内实际使用的字母、数字或 F1～F11。音效快捷键触发后松开 Ctrl/Shift/Alt，软件先按住说话键再播放，结束后松开。自动按键只在 UAGame 游戏窗口前台时生效。

真人说话仍按游戏原有方式操作；自由麦不需要按 T。切到其他窗口、停止、切换音效或退出时，会释放软件按住的键；不会代为松开用户原本自己按住的键。

### 音量与发送增强

- 音效音量：控制文字朗读和录音的响度，播放途中调整立即生效。
- 麦克风音量：只控制真人声，最高 400%。
- 发送增强：×1～×8，默认 ×2，放大送往游戏的真人声和音效，带峰值保护。
- 发送电平：显示实际生成的发送音频峰值。未开启混音时，麦克风音量和发送增强不生效。

可以从麦克风 200%、发送增强 ×2开始试，按队友反馈调整。修改后点击“保存并应用”记忆设置。

### 音效与快捷键

录音音效默认 Ctrl+Shift+1～8，文字短句默认 Ctrl+Alt+1～8。右侧“声音小档案”可以改名称、用途、文字和快捷键。热键冲突会在窗口底部提示。

新增短句可导入未压缩 WAV，文件会复制到数据目录。条目有录音时优先播放录音；清除录音后使用文字朗读。自然度取决于 Windows 已安装的桌面语音音色。

隐藏语音窗口仍会转发麦克风，以便回到游戏继续使用。点击“关闭麦克风混音”或退出整个软件才停止；下次启动不会自动开启真人麦克风。

## 4. 常见问题

| 问题 | 检查项 |
| --- | --- |
| 耳机听到游戏声，软件没有波形 | 重新选择游戏实际使用的输出设备；设备切换/断开后停止并刷新再开始 |
| 本机能听到音效，队友听不到 | 是否真正开启混音；游戏麦克风是否选 CABLE Output；按键/自由麦模式是否一致 |
| 真人声很小 | 是否选择实体麦克风，尝试调麦克风音量与发送增强，观察发送电平 |
| 列表里没有 CABLE Input | 安装随附组件并按提示重启，再刷新设备 |
| 提示组件已安装但设备未就绪 | 重启，检查 Windows 声音中设备是否启用，再刷新 |
| 监听快捷键不工作 | 在“软件设置”中换一个包含 Ctrl/Alt/Shift/Win 的组合；其他程序可能已占用该组合 |
| 相似物品被一起显示 | 声音可能本来相同，按占格和方向进一步筛选 |
| HUD 盖不住游戏 | 优先使用无边框全屏或窗口化，普通置顶不能覆盖所有独占全屏 |

## 5. 备份与卸载

备份 `%LOCALAPPDATA%\FieldTrader` 整个目录，包含 `catalog.json`、图片/样本、`voiceboard.json`、`voiceboard-audio` 和其他设置。卸载本软件会保留个人数据库，也不会自动卸载共享的 VB-CABLE 驱动。
